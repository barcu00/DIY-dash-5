# OpenDash v0.2 UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace placeholder letter icons with readable 16x16 motorsport pictograms for every project parameter, finish the 800x480 DASH/TRACK/DIAG/SETTINGS layouts, preserve horizontal page swiping, add vertical scrolling where needed, and remove instructional placeholder copy.

**Architecture:** Keep the existing `ParameterRegistry -> IconCatalog -> IconAssets -> Ui` path. `IconCatalog` remains the single mapping from all 90 stable `ParameterId` values to semantic icons; `IconAssets` renders deterministic 1-bit 16x16 masks using simple drawing primitives. The four top-level pages remain the horizontal ring `DASH -> TRACK -> DIAG -> SETTINGS -> DASH`; SETTINGS uses a vertically scrollable content container so horizontal page gestures remain available.

**Tech Stack:** C++17, Arduino-ESP32, LVGL 8.4, PlatformIO, native Unity tests.

**Spec:** `docs/superpowers/specs/2026-09-01-opendash-v0.2-ecumaster-configurable-ui-design.md`

## Global Constraints

- Hardware: Waveshare ESP32-S3-Touch-LCD-5 non-B, 800x480.
- Keep 12 configurable DASH slots and 12 configurable TRACK slots.
- Keep horizontal swipe navigation with no dots/page number.
- Keep icons at 16x16 to avoid increasing per-tile RAM.
- Every `ParameterId` 0..89 must resolve to a non-invalid default icon.
- Hidden tiles remain editable from DASH/TRACK LAYOUT.
- No fallback from a real ECU source to MOCK.
